title: 회원 목록 확인하기
---

## 이 기능은?

가입한 회원 전체를 조회하고, 상태와 가입일을 확인합니다.

## 어디에 있나요?

로그인 직후 첫 화면입니다. 다른 화면에 있을 때는 상단 메뉴의 **회원 관리**를 누르세요.

## 화면 구성

![회원 관리 화면](admin-01-members)

1. **회원 검색** — 이름으로 회원을 찾습니다.
2. **신청 승인** — 대기 중인 가입 신청을 승인합니다. → 기능 3 참고

## 방법

1. 목록에서 회원의 상태와 가입일을 확인합니다.
2. 특정 회원을 찾으려면 상단의 **회원 검색**에 이름을 입력합니다.

> 목록은 가입일이 최근인 회원부터 표시됩니다.

## 그러면?

조건에 맞는 회원만 목록에 남습니다.

## 안 될 때는?

- 목록이 비어 있으면 검색어를 지우고 다시 확인하세요.
- "불러오지 못했습니다"가 나오면 새로고침한 뒤 다시 시도하세요.
